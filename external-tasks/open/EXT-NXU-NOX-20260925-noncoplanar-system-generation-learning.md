# EXTERNAL TASK — Non-coplanar planetary systems + learning scenario

- **Origin:** NOXIA Universe / OTA
- **Target:** NOXIA Game
- **Date:** 2026-09-25
- **Status:** open

## Request
Extend the procedural system-generator design beyond near-coplanar textbook systems.

Support scientifically constrained distributions for prograde, inclined, strongly misaligned and rare retrograde architectures. Preserve a distinction between generated ground truth and what the player has observationally inferred.

## Gameplay
Orbital-plane differences should affect transfer planning and delta-v rather than exist only visually. Astronomy/prospecting can progressively reveal system architecture and improve route planning.

## Learning module
Create an optional discovery scenario that begins with a simplified disk model and confronts the player with a strongly misaligned/retrograde planet. Let the player combine transit geometry, radial velocity and spin-orbit observations to compare plausible formation histories.

Teach angular momentum, inclination, migration and observational inference through play. Do not present unresolved hypotheses as established facts.
