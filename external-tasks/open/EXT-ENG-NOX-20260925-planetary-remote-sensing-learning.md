# EXTERNAL TASK — Planetary Remote Sensing Layer + learning module

- **Origin:** Engineering / OTA / NOXIA Universe
- **Target:** NOXIA Game
- **Date:** 2026-09-25
- **Status:** open

## Request
Design a unified observation layer in which the simulation knows planetary ground truth but players know only what their instruments and analyses have established.

Combine transit photometry, radial velocity, spectroscopy, direct imaging, astrometry and radio astronomy. Observations should progressively constrain properties rather than simply unlock a complete planet card.

Track measured, inferred, uncertain and unknown values separately. Allow hypotheses to be revised by later observations.

## Learning scenario
Create an optional Beta-Pictoris-inspired radio scenario:
1. Detect an unusual radio source.
2. Determine position/localization relative to star and planet.
3. Inspect frequency range and circular polarization.
4. Compare plausible source mechanisms.
5. Infer an auroral electron-cyclotron-maser interpretation.
6. Derive a magnetic-field constraint, explicitly as an inference/lower bound.
7. Plan follow-up observations that could strengthen, revise or falsify the interpretation.

Teach signal -> measurement -> interpretation -> uncertainty, not 'radio signal = aliens' and not a quiz. Integrate with the previously requested non-coplanar planetary-system learning work.
