# EXTERNAL TASK — Adaptive factory gameplay + learning module

- **Origin:** Engineering / OTA / NOXIA Universe
- **Target:** NOXIA Game
- **Date:** 2026-09-25
- **Status:** open

## Request
Design factories as systems rather than static production-bonus buildings.

Represent machines/cells, material flow, storage, energy, maintenance, production orders, sensors, robotics and later digital-twin/adaptive-control capabilities. Allow production constraints to emerge from actual bottlenecks.

Connect to the Energy Grid Layer and MiniNode/robot-swarm systems: flexible production and charging can shift with power availability; robots can be reassigned to logistics, inspection, maintenance or production.

## Learning module
Create an optional scenario progression:
1. Operate a conventional fixed production line.
2. Instrument it and observe bottlenecks.
3. Introduce a digital twin.
4. Test a change in simulation before deployment.
5. Add adaptive scheduling/control.
6. Introduce a sensor/model error so twin and reality diverge.
7. Diagnose, revalidate and recover.

Teach that a digital twin is a model, not the physical system itself. Prefer visible causal flows and before/after metrics over quizzes or exposition. Keep normal gameplay compatible with the same underlying simulation.
