## Request
Design MiniNode robot swarms as a gameplay system without implementing prematurely.

## Gameplay model
Players should be able to deploy heterogeneous nodes for scouting, prospecting, relay networking, transport, manipulation, maintenance and later construction. Individual nodes are expendable/recoverable assets; capability emerges from composition, coordination, energy and communications rather than a single monolithic robot.

Model research/unlocks, manufacturing inputs, node inventory, energy/charging, bandwidth/latency, autonomy level, losses/recovery, maintenance and task assignment. Planetary environments should change useful swarm composition.

Keep canonical science/entities in KG/OTA and world history in noxia-universe. This request owns gameplay, balancing and runtime-facing contracts only.
