# SSF → NOXIA: gestufte Wissensstruktur `UNL:NOX:mars-habitat` — erledigt

**Status:** done — 2026-08-29

`UNL:NOX:mars-habitat` ist kanonisch ein Integrations-/Master-Unlock und gibt `BLD:NOX:mars-habitat-1` frei.

Kanonische Vorstufen:
- `UNL:NOX:pressure-systems`
- `UNL:NOX:airlock` (nach pressure-systems)
- `UNL:NOX:life-support` (nach pressure-systems + water-processing + power-generation)
- `UNL:NOX:thermal-control` (nach power-generation)
- `UNL:NOX:radiation-protection`
- `UNL:NOX:environment-monitoring` (nach power-generation)
- `UNL:NOX:habitat-redundancy` (nach life-support + environment-monitoring)

Master-Voraussetzungen sind alle obigen Vorstufen plus `UNL:NOX:water-processing` und `UNL:NOX:power-generation`.

Prinzip: kleine Wissenseinheit → kleiner Unlock → sichtbarer Spielerfolg → Integration. SSF liefert die Lernpfade; NOXIA besitzt Unlock-Semantik und Progression.

Umsetzung der Lernpfade wurde an SSF weitergereicht; technische Dossiers wurden separat beim OverTime Archive angefragt.
