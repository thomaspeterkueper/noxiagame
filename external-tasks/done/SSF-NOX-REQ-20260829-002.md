# SSF → NOXIA: `UNL:NOX:resource-extraction` — erledigt

**Status:** done — 2026-08-29

Kanonische ID bestätigt: `UNL:NOX:resource-extraction` („Rohstoffgewinnung I“).

Scope: Deposit → Entnahme/Abbau → Zerkleinerung → Trennung/Anreicherung → Gewinnung/Aufbereitung → nutzbarer Rohstoff/Handelsgut; einschließlich Ausbeute, Reinheit, Energie-/Wasserbedarf und Reststoffen. Damit ist der Unlock bewusst ein Basispfad und keine Spezialisierung auf einzelne Rohstoffklassen.

Spielwirkung: `BLD:NOX:mine-1` und basale Rohstoffgewinnung aus Deposits. Spezialisierte Verfahren erhalten später eigene Unlocks.

SSF-Mappingvertrag: Das zuständige SSF-Modul gibt `UNL:NOX:resource-extraction` in `module.unlocks[]` zurück.

Umsetzung des SSF-Lernpfads wurde an SSF weitergereicht.
