# Dashboard: Standortbilder und Profilwerte

Status: done — 2026-08-28

## Umsetzung
- Vorhandene Assets aus `public/images/locations/` werden für Erde, Mond, Mars, Phobos und Prometheus in der bestehenden Ortsnavigation verwendet.
- `Trades`, `Flüge` und `Wissen` erscheinen kompakt im Sticky-Header und öffnen per Klick weiterhin das Vollprofil.
- Keine neue große Profilkarte und keine neuen Bildassets.

## Ursprüngliche Anforderung
Das NOXIA-Dashboard soll vorhandene Standortbilder in `Deine Orte` nutzen und die persönlichen Werte `Trades`, `Flüge` und `Wissen` kompakt dauerhaft sichtbar machen, ohne die Grid-Fläche wesentlich zu verkleinern.
