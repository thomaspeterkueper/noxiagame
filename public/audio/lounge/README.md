# Lounge-Musik

Hier liegen die Titel für Café, Bar, Restaurant und Kneipe (MP3, ruhig, ohne lauten Anfang).

Neuer Titel:
1. Datei in diesen Ordner legen, z. B. `lounge-01.mp3`.
2. In `lib/game/music/lounge.ts` in `LOUNGE_TRACKS` eintragen: `{ file: 'lounge-01.mp3', title: 'Titel' }`.

Solange die Liste leer ist, bleibt der Gastraum still und der Musikschalter erscheint nicht.
