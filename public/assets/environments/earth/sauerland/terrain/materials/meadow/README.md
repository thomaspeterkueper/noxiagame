# Sauerland Meadow Materials

Status: production candidates for `GFX-SAU-001`.

## Current assets

- `meadow_base_01.webp` — first calm meadow base-material candidate.

## Usage contract

- continuous-world source material, not a visible map tile;
- no rhombus frame, soil sidewall, label, logo or presentation background;
- high-interest rocks, flowers, shrubs and tufts belong in separate detail layers;
- base materials must remain quiet enough for large-area repetition;
- do not mark an asset `ACCEPTED` until it passes a large-area repetition/seam test.

## Current review state

`meadow_base_01.webp` is **REVIEW**, not yet canonical. It must be checked for edge continuity and recognisable repetition before additional meadow variants are derived from it.
