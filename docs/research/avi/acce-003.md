# ACCE-003 — Historical Closure vs Embodied Disposition

**Status:** executable falsification-oriented reference experiment  
**Date:** 2026-10-07

## Question

If two agents have the same reduced visible present state but different histories and respond differently to the same stimulus, does closure require history itself, or is a presently embodied disposition sufficient?

## Protocol

A and B share the same visible state, base reflex profile and sudden-sound stimulus. Their histories differ: A has repeated safe exposure; B has harmful exposure. The existing NOXIA reflex runtime converts these histories into bounded habituation/sensitization.

The reduced reconstruction omits adaptation and therefore predicts no history-dependent response difference. The completed reconstruction adds the currently embodied adaptation, not an episode list or primitive history variable.

## Gate

A stronger historical carrier is admissible only if the response defect remains after all measurable present dispositions relevant to the response have been restored.

Expected result for the current model:

1. same reduced visible present state;
2. different histories;
3. non-zero response defect when embodied adaptation is omitted;
4. exact closure when current adaptation is restored;
5. refusal to introduce history itself as an extra carrier.

## Scientific meaning

ACCE-003 distinguishes two claims that must not be conflated:

- **weak/path-encoded dependence:** history matters because it changed the present structure;
- **strong/history-irreducible dependence:** even a complete present state fails to screen off history.

The current reflex model is deliberately expected to support only the first claim. A PASS therefore does **not** establish strong ontological path dependence. It demonstrates a diagnostic rule: before treating history as an additional state carrier, search for presently embodied traces that restore closure.

This also sharpens the meaning of a trace: a trace need not be an explicit representation of a past episode. Habituation or sensitization can be a present structural consequence of history.

## Next gate

A later experiment may compare richer agents whose measurable present states are matched across memory, physiology, learned policy and reflex adaptation. Only a reproducible residual response difference after that closure audit would motivate an AVI candidate for history-irreducible state.
