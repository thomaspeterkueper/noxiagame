# Teilprojekte

NOXIA wird in Teilprojekten bearbeitet, je eines pro Chat. Jedes Teilprojekt hat eine Datei in diesem Ordner: Zuständigkeit, maßgebliche Dokumente, offene Aufgaben und Anschlussstellen zu den anderen.

Regeln:

- Ein Chat baut nur in seinem Teilprojekt. Was ein anderes berührt, wird dort als Aufgabe eingetragen, nicht selbst gebaut.
- Aufgaben stehen in der Datei des Teilprojekts, das sie erledigen soll. Erledigtes wird mit Commit abgehakt.
- Geld bewegt sich nur nach `docs/decisions/NOXIA-FIN-0001-solar-finance-alignment.md`: Transfer, Fiskaltransfer, ausgewiesene Emission oder Senke.
- Figuren wissen nur, was sie im Raum wissen können.

| Teilprojekt | Datei | Zuständig für |
|---|---|---|
| Bevölkerung und Ökonomie | `population-economy.md` | Bedürfnisse, Affekt, Beziehungen, Wohnen, Stellen, Geldkreislauf, Forschungslauf |
| Gastronomie | `hospitality.md` | Café, Bar, Restaurant: Innenaufbau, Figuren, Gespräche, Bedienoberfläche |
