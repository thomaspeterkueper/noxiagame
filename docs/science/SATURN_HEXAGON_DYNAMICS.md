# Saturn Hexagon / Polygonal Atmospheric Dynamics

Status: NOXIA science integration seed, 2026-09-29

## Gameplay principle
The Saturn hexagon is a research environment, not a solved landmark.

Players deploy atmospheric probes across latitude, altitude and time, recover wind/temperature/tracer profiles, and compare observations against competing model families.

## Evidence states
`observed -> analogue-supported -> model-supported -> discriminating evidence -> validated interpretation`

No model becomes canonical truth merely because it generates a hexagon.

## Mission variables
- probe latitude/altitude
- temporal sampling
- wind-vector profile
- temperature/stratification profile
- tracer transport
- perturbation/wave structure
- instrument uncertainty

## Research questions
- Is the six-fold structure consistent with barotropic instability?
- Which observations support or disfavor a planetary-wave interpretation?
- How strongly does internal heat forcing constrain viable models?
- Can rapid rotation explain part of the observed persistence?
- What vertical observations would discriminate shallow from deeper coupling?
