# NPC cognition: routine, sleep, creativity and insight

NOXIA uses cognition as an escalation ladder, not a permanent expensive agent loop.

`routine (L0) → reactive (L1) → deliberative/exploratory (L2) → insight candidate (L3)`

Sleep is L0. Active perception and planning are suppressed; bounded memory consolidation can rank autobiographical memories for retention/replay. Dreaming and meditation may recombine existing memories and knowledge, but cannot create facts.

## Creativity

Creativity is multidimensional: novelty seeking, associative range, routine stability, cognitive flexibility and idea threshold. Extreme creativity can make routine interruption more likely while increasing unusual problem-solving. It does not imply competence or privileged knowledge.

## Insight gateway

KG/OTA or other higher-level knowledge sources may eventually provide bounded inspiration references only after an unresolved problem reaches the insight gate. The NPC receives a hypothesis, not source truth. Every candidate is stored with provenance and `canonical=false`; validation must occur through normal research/world actions before knowledge can change.

## Cost invariant

Routine and sleep require no external model. L1/L2 remain deterministic. L3 creates an auditable candidate and still performs no provider call by itself. Any future external inference remains a separately budgeted escalation.
