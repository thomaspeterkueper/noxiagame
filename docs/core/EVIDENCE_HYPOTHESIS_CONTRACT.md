# Evidence and Hypothesis Contract

Hypotheses are epistemic objects, not Ground Truth and not reconstructed Core events.

The first bounded reconstruction layer is:

`Observation → PersonKnowledge → Evidence Set → declared Hypothesis → confidence/status → further information gathering`

Rules:
- Core historical events remain inaccessible to the inference function.
- A domain must declare candidate hypotheses and evidence rules; the generic Core does not invent causes.
- Every assessment retains the exact knowledge IDs used as evidence.
- Contradictory evidence is first-class and can produce `contested`.
- Missing evidence keeps a hypothesis provisional.
- Same definition + same knowledge yields the same assessment.
- Hypothesis confidence is not action authority and cannot bypass Decision Sufficiency.
- LLM generation/ranking is explicitly outside this first slice.

This permits later archaeology, accident investigation, prospecting and scientific research without giving actors privileged access to history.
