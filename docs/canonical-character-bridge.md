# Canonical Character Bridge

NOXIA can simulate people who also exist in novels or other Universe canon.

The bridge binds identity only. Canonical biography and fixed historical facts remain authoritative in the external Universe/ORE source. Runtime location, assignments, health, relationships, memories, hypotheses, cognition and emergent events remain owned by the normal Living Population simulation.

A canonical character therefore:
- uses the same legal actions and simulation rules as every other Person;
- receives no privileged ground truth from the author's canon;
- can form hypotheses only from observations available to that person;
- can accumulate emergent game memories without silently rewriting canon;
- can be constrained to a valid simulation interval.

This keeps canonical characters causal inhabitants rather than scripted cameos and remains compatible with the newer cognition/hypothesis runtime.
